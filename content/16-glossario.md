---
title: Glossário
description: Os termos usados no sistema, em ordem alfabética.
group: Referência
---

| Termo | Significado |
|---|---|
| **Alinhamento** | Casamento das palavras do roteiro com as palavras ouvidas no áudio. Precisa cobrir 90% do roteiro. |
| **Anchor** | O instante em que a narração diz o termo que nomeia um desenho. O desenho termina nesse instante. |
| **anchorTerms** | As palavras literais da fala que o diretor aponta como anchor de cada cena. |
| **Beat** | Trecho de cerca de 4 s dentro de uma cena, cortado nas pausas reais da fala. |
| **Bíblia visual** | Inventário das decisões visuais do vídeo: o que cada cena usa e o que falta. |
| **Canal** | Canal de vídeo de um nicho, com idioma, voz e estilo padrão. |
| **Catálogo** | Todas as imagens prontas de um nicho, lidas dos manifestos da galeria. |
| **Cena** | Trecho curto do roteiro, com uma ou poucas frases. |
| **Citação** | Frase curta e completa da própria fala desenhada numa caixa. |
| **Cobertura** | Lista das imagens que o roteiro precisa e que ainda não existem. |
| **Conceito** | Ícone de uma ideia abstrata (dinheiro, tempo, alerta). Também precisa de PNG. |
| **Contorno** | Caminho que a ponta da caneta percorre ao desenhar uma imagem. |
| **Diretor semântico** | A IA que lê o roteiro e decide o que mostrar em cada cena. |
| **Edit-report** | Relatório de qualidade do plano, com as travas e métricas. |
| **Estado** | Rótulo sobre a imagem principal da cena ("Baixo", "Gasta"). |
| **Estilo do vídeo** | Explicativo, reflexivo, impacto ou comparativo: ritmo das páginas e orientação ao diretor. |
| **Galeria** | As imagens de um nicho, oficiais e importadas. |
| **Hotwords** | Palavras do roteiro passadas ao reconhecimento de fala como dica de vocabulário. |
| **Imagens pedidas** | Pedidos do diretor para imagens que a galeria não tem, com nome e prompt. |
| **Microtexto** | Frase curta (2 a 6 palavras) escrita nas pausas entre desenhos. |
| **Nicho** | O assunto de um conjunto de canais. Tem galeria e perfil próprios. |
| **Página** | Uma tela de quadro branco que junta cenas do mesmo assunto. |
| **Perfil do nicho** | Assunto, estilo das imagens, pessoas recorrentes e conceitos extras de um nicho (`nicho.md`). |
| **Pessoas recorrentes** | Quem aparece em vários vídeos do nicho, com aparência fixa. |
| **Plano do vídeo** | O arquivo com todas as decisões; o render só o segue. |
| **Prévia de 60 s** | Plano completo com render só do primeiro minuto. |
| **Relação** | Ligação entre dois desenhos que vira seta (causa, sequência, contraste...). |
| **Render** | O desenho final do vídeo, quadro a quadro. |
| **Roteiro** | O texto do vídeo, fonte de tudo que aparece escrito. |
